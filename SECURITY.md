# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Use GitHub private vulnerability reporting:

1. Go to the Security tab of this repository.
2. Select "Report a vulnerability".
3. Describe the problem and the steps to reproduce it.

Only the maintainer can see the report.

## Supported versions

Only the latest commit on `main` is supported. A fix goes to `main`.

## Response

This is a project with one maintainer. There is no promise of a response time.
